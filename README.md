# E-Commerce Website

Features


🏠 Home Page with featured products

📦 Product Listing Page with cards displaying:
  
      Product image
      
      Name & brand
      
      Price
      
      Add to Cart button

🔍 Product Details Page with:

      Large product preview
      
      Category, description & price
      
      Stock availability
      
      Add to Cart functionality

🛒 Cart System for adding products

➕ Add / Update / Delete Product functionality

🌙 Dark Mode UI for better user experience

📱 Responsive Design for different screen sizes

🧰 Tech Stack Frontend
    
      HTML5 – Structure of the web pages
      
      CSS3 – Styling, layout, and responsive design
          
      JavaScript – Dynamic behavior and interactivity
     
  UI & Design
       
      Dark Theme UI  
      
      Flexbox & Grid for layout  
      
      Custom Cards & Buttons
    
  Tools & Platform
    
      Git & GitHub – Version control
      
      VS Code – Development environment


🔐 Backend Tech Stack
  
  Java
  
    Core programming language used for backend development.

  Spring Boot
      
      Used to build a scalable and maintainable backend application.
      Helps in creating REST APIs quickly with minimal configuration.

  Spring Web (REST APIs)

      Used to handle HTTP requests and responses between frontend and backend
      (e.g., products, cart, stock management).

  Spring Data JPA

      Used to interact with the database easily using Java objects instead of SQL queries.

  Hibernate

      ORM (Object Relational Mapping) tool that maps Java classes to database tables.

  PostgreSQL Relational database used to store:

      Product details
      
      Categories
      
      Stock information
      
      User data (future scope)
